Лабораторна робота №3 присвячена оцінюванню потенційної шкоди для здоров’я населення під впливом певного забруднювача. У роботі використовуються ключові токсикологічні показники CDI, HQ та CR.

CDI (Chronic Daily Intake) характеризує середню добову кількість речовини, що надходить в організм протягом тривалого часу. Він обчислюється на основі концентрації забруднювача, кількості середовища, яке людина споживає, тривалості та частоти впливу, маси тіла та періоду усереднення.

HQ (Hazard Quotient) застосовується для визначення рівня неканцерогенного ризику — порівняння отриманого навантаження з референтною дозою.

HQ < 1 — ризик прийнятний

1 ≤ HQ ≤ 4 — середній ризик

HQ > 4 — потенційно висока небезпека

CR (Cancer Risk) оцінює ймовірність розвитку онкологічних захворювань при дії канцерогенних речовин. Він обчислюється як добуток CDI та канцерогенного коефіцієнта.

Для розрахунків застосовуються такі параметри: концентрація забруднювача, добовий обсяг споживання води/повітря, кількість днів експозиції, роки впливу, маса тіла, час усереднення, референтна доза та канцерогенний фактор. Кожен із цих параметрів впливає на підсумкову оцінку ризику.

Реалізація

Проєкт створено на стеку MERN (MongoDB, Express, React, Node.js). У цій роботі база даних не використовується, оскільки всі розрахунки виконуються на основі введених користувачем параметрів.

Серверна частина (Node.js, Express)

Сервер містить:

модуль для математичних обчислень,

маршрути для обробки запитів,

генератор тестових значень,

набір unit-тестів.

Основні обчислення виконує функція compute, яка:

перевіряє коректність даних,

визначає час усереднення,

розраховує CDI, HQ та CR,

визначає рівні ризику,

повертає результати або повідомлення про помилки.

Клієнтська частина (React)

Клієнт містить:

API для взаємодії із сервером,

форму введення параметрів,

генератор випадкових даних,

компонент відображення результатів.

Форма забезпечує:

введення всіх параметрів моделі,

генерацію тестових значень,

запуск розрахунку,

виведення помилок.

Компонент результатів показує:

CDI, HQ, CR,

рівні ризику,

текстові пояснення.

Особливості реалізації

ретельна перевірка введених значень;

автоматичний вибір часу усереднення;

обробка помилок на рівні API;

генерація реалістичних синтетичних даних;

unit-тести для перевірки математичної моделі.
